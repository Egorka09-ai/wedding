# Приглашение на свадьбу — Егор и Алеся

Одностраничный сайт-приглашение. 7 ноября 2026, Магнитогорск.
Без сборки и зависимостей: весь код в `index.html`.

## Запуск

Открыть `index.html` в браузере. Либо в VS Code:
Live Server → Open with Live Server.

## Структура страницы

1. Конверт с восковой печатью — тап открывает приглашение и запускает музыку
2. Обложка: «Жили-были», имена, царевна-лягушка (SVG)
3. Текст приглашения
4. Скретч-дата: три кувшинки стираются пальцем
5. Таймлайн дня (13:45 / 16:00 / 17:00 / 22:00)
6. Обратный отсчёт до 7 ноября 2026, 13:45 (+05:00)
7. Адреса ЗАГСа и банкетного зала «Мёд» + ссылки на Яндекс Карты
8. Дресс-код: палитра вечера
9. О подарках
10. Финал

## Где что править

| Что | Где искать в `index.html` |
|---|---|
| Цвета | блок `:root` в начале `<style>` |
| Шрифты | `--display` (Marck Script), `--serif` (Alice) |
| Дата отсчёта | `var target = new Date("2026-11-07T13:45:00+05:00")` |
| Дата на кувшинках | три блока `<div class="tile">` |
| Тайминг дня | секция с классом `timeline` |
| Адреса и карты | секция `.place`, ссылки `.map-link` |
| Палитра дресс-кода | блок `.swatches`, шесть `<div class="sw">` |
| Лягушка | `<svg class="frog">` |
| Мелодия | массив `MELODY` (полутона от A3=220 Гц и длительность в долях) |
